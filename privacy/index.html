隱私權政策

最後更新日期：2026 年 8 月 4 日

本站（靖諺的資訊學習筆記，https://www.tseng-school.com ）是一個個人性質的學習筆記網站，內容以 APCS、CPE、LeetCode 解題與演算法筆記為主。

本站是靜態網站，站方本身沒有會員系統、沒有資料庫，也不會主動要求你提供姓名、電子郵件或任何個人資料。你可以完全匿名地瀏覽本站的所有文章。

不過，本站使用了若干第三方服務來提供廣告、統計、留言與前端資源，這些服務會在你的瀏覽器中放置 Cookie 或取得你的連線資訊。以下逐項說明。

一、本站使用的第三方服務

Google AdSense（廣告）

本站顯示由 Google AdSense 提供的廣告，以不影響觀看體驗投放為主。

  • Google 作為第三方供應商，會使用 Cookie 在本站放送廣告。
  • Google 使用廣告 Cookie，可根據你先前造訪本站或其他網站的紀錄，向你放送廣告。
  • 與 Google 合作的第三方廣告供應商，也可能使用 Cookie 或類似技術來衡量廣告成效。
  • 本站無法存取、也不會保存這些 Cookie 的內容。

你可以透過下方「三、你的選擇權」停用個人化廣告。

Google Analytics（流量統計）

本站使用 Google Analytics 4 了解哪些文章比較多人閱讀，以決定後續要補寫什麼內容。它會蒐集你的裝置類型、瀏覽器、大致地理位置（通常到城市層級）、來源網站與你在站內的瀏覽路徑。這些資料以彙總形式呈現，本站看到的是統計數字，不是個別讀者的身分。

giscus（留言）

文章下方的留言功能由 giscus 提供。

  • 留言前需要以你的 GitHub 帳號授權登入。
  • 你的留言內容、GitHub 使用者名稱與頭像都是公開的，任何人都看得到，也會被搜尋引擎收錄。
  • 本站不會取得你的 GitHub 密碼。授權範圍與撤銷方式請見 GitHub 的應用程式設定。
  • 請勿在留言中填寫你不希望公開的個人資訊。

不蒜子（訪客計數）

頁面底部的訪客數與總瀏覽次數由第三方服務「不蒜子」（busuanzi.ibruce.info）統計。它會讀取你的 IP 位址與瀏覽器識別字串來去除重複計數，本站只會拿到最後的數字。

Google Fonts、jsDelivr（前端資源）

本站的中文字型來自 Google Fonts，數學公式排版（MathJax）與圖片瀏覽等元件來自 jsDelivr CDN。載入這些資源時，你的瀏覽器會向 Google 與 jsDelivr 的伺服器發出請求，對方因此可取得你的 IP 位址與瀏覽器識別字串。

GitHub Pages（網站代管）

本站代管於 GitHub Pages。GitHub 基於維運與資安目的，會保留伺服器存取紀錄。

關於站內搜尋

本站的搜尋功能完全在你的瀏覽器中執行，搜尋字詞不會被傳送到任何伺服器，也不會被記錄。

二、Cookie 說明

Cookie 是網站存放在你瀏覽器中的小型文字檔。本站自身不會寫入任何 Cookie，頁面上出現的 Cookie 全部來自上述第三方服務，主要用於廣告投放與流量統計。

你可以在瀏覽器設定中封鎖或刪除 Cookie。停用 Cookie 不會影響你閱讀本站文章，但可能導致留言功能無法正常登入。

三、你的選擇權

你隨時可以：

  • 前往 Google 廣告設定 關閉個人化廣告，或調整 Google 用來投放廣告的興趣類別。
  • 前往 aboutads.info 或 Your Online Choices 一次停用多家廣告聯播網的個人化廣告。
  • 在瀏覽器中封鎖第三方 Cookie，或使用瀏覽器的「請勿追蹤」與內容封鎖功能。
  • 使用廣告封鎖擴充套件。本站不會因此限制你閱讀任何內容。

停用個人化廣告後，你仍會看到廣告，只是廣告內容與你的瀏覽紀錄無關。

四、歐洲經濟區、英國與瑞士的訪客

若你位於歐洲經濟區、英國或瑞士，本站會在你首次造訪時顯示同意聲明橫幅，讓你選擇是否同意第三方使用 Cookie 進行廣告與評估。你可以隨時透過該橫幅的「管理選項」變更你的選擇。

五、對外連結

本站文章中包含指向其他網站的連結（例如題庫平台、參考文獻、GitHub 儲存庫）。這些網站有各自的隱私權政策，不在本政策的範圍內，本站對其內容與資料處理方式不負責任。

六、未成年讀者

本站不會刻意向未成年人蒐集個人資料。若你未滿十八歲，建議在留言前先與家長或監護人討論，並避免在公開留言中透露真實姓名、就讀學校、聯絡方式等資訊。

七、本政策的修訂

當本站新增或移除第三方服務時，本政策會隨之更新，並修改頁面上方的「最後更新日期」。重大變更會在文章列表或本頁面明確說明。

八、聯絡方式

對本政策有任何疑問，或希望本站移除某則留言、某項資料，歡迎來信：

  • 電子郵件：mail@tseng-school.com
